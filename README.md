# Análisis de Datos - DENUE INEGI (Sector 11)

Este repositorio contiene el procesamiento y análisis de los datos del **Directorio Estadístico Nacional de Unidades Económicas (DENUE)** correspondientes al sector 11 (Agricultura, cría y explotación de animales, aprovechamiento forestal, pesca y caza).

##  Contenido del Proyecto
- `denue_inegi_11_.csv`: Dataset original con información de unidades económicas.
- El análisis se centra en la distribución geográfica y tipos de actividades económicas en las entidades registradas.

## Herramientas utilizadas
- **Excel / CSV** para la gestión de datos.
- **GitHub** para el control de versiones y entrega del proyecto.

##  Datos Relevantes
El archivo incluye columnas críticas como:
- `nom_estab`: Nombre del establecimiento.
- `nombre_act`: Actividad económica específica.
- `entidad`: Estado de la república donde se ubica.
- `latitud` y `longitud`: Ubicación geoespacial.
